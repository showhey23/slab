Foundations は Associate と Architect に分かれています。両者は対象者も出題範囲も別物です。Associate は Claude を業務の生産性ツールとして使う非開発者向け（7ドメイン）、Architect は Claude Code / Agent SDK / API / MCP で本番アプリを設計する技術者向け（5ドメイン＋6シナリオ）。どちらか一方の学習でもう一方はカバーできません。
